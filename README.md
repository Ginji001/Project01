# ハチワレバレット — 開発用ミラー

このブランチは **ハチワレバレットの安全な開発用コピー** です。

## 本番

- 現在の本番URL: `https://hibicho-daily-journal.emiya2170.chatgpt.site/`
- 2026-09-04: ユーザー確認で、別端末にも最近の記録が表示されることを確認。
- したがって、本番側には端末間同期の仕組みが存在すると判断しています。

## 重要

このGitHub版は再構築した静的PWAで、保存先はブラウザの `localStorage` です。
**本番サイトの同期バックエンド／認証処理はこのブランチに含まれていません。**

そのため、同期方式を回収・再現・テストできるまでは、このブランチを本番URLの置き換えには使用しません。
本番サイトと本番データは変更しません。

## 開発方針

- 本番データをGitHubへ保存しない
- APIキー・パスワードを置かない
- 変更は `hachiware-bullet` ブランチだけで行う
- `master` は変更しない
- 本番へ反映する前に、同期・データ保持・PWA動作を別環境で確認する

## 編集対象

- `src/app.js` — アプリ機能
- `src/styles.css` — デザイン
- `index.html` — 画面の土台
- `manifest.webmanifest` — PWA設定
- `sw.js` — オフラインキャッシュ

圧縮ファイルを介さず、通常のソースを直接編集できる構成に整理済みです。
